## 🎯 Different Strategies to Demo

### **1. Single Strategy**
- Uses only one model (fastest)
- Shows: "Used GitHub Models"
- Cost: $0.00

### **2. Specialized Strategy** (Recommended)
- Routes to best model for task type
- Shows: "Used GitHub for breakdown"
- Cost: $0.00 (usually uses free models)

### **3. Fallback Strategy**
- Tries cheap models first
- Shows: "Tried GitHub → Success"
- Cost: $0.00 (stops at first success)

### **4. Ensemble Strategy**
- Uses ALL 3 models
- Shows: "GitHub: 1 request, Groq: 1 request, DeepSeek: 1 request"
- Cost: ~$0.0008 per issue
- Most accurate!
